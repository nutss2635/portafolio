Práctica 1 — Administración de BBDD · SQL Server

Migré la base de datos SQL Server local de la empresa a un servidor SQL Server en Amazon AWS. Analicé la estructura y los tipos de datos de la BBDD original y reconstruí el esquema en la nube (tablas, desencadenadores y diagramas) replicando el modelo existente. Diseñé la estrategia de carga masiva para subir la información (datos tributarios del SII, productos, facturas de compra y venta, clientes y proveedores), logrando la migración de más de 4.000 registros con cero pérdida de datos. Para validar y presentar el resultado, desarrollé una página en PHP conectada a la nueva base de datos, con tablas y filtros para consultar toda la información migrada. A partir de este trabajo, propuse a la empresa incorporar en su sitio web un portal donde sus clientes pudieran revisar sus propios datos de ventas y facturación.

Proyecto · Freelance

Agenda para barbería

Sistema de reservas online para una barbería. Los clientes eligen servicio, barbero y horario disponible desde el navegador, mientras el barbero gestiona su agenda y sus clientes. Incluye automatizaciones por correo: recordatorio diario de las citas, cierre automático de las atenciones e invitación a calificar el servicio, todo mediante tareas programadas.

Tecnologías utilizadas

Next.js 16Framework: App Router, TypeScript y Tailwind CSS.
SupabaseBase de datos (Postgres) y autenticación del barbero.
Nodemailer + GmailEnvío de correos a los clientes.
Vercel CronAutomatizaciones: recordatorios, cierre de citas e invitación a calificar.
VercelHosting y despliegue.

Proyecto · Freelance

Tótem CESFAM

Rediseño del tótem de auto-atención de la farmacia de un CESFAM. El paciente ingresa su RUT y el sistema lo clasifica automáticamente en atención general o preferencial consultando su ficha (edad, embarazo o discapacidad), en lugar de preguntárselo. Consta de tres vistas conectadas en tiempo real: el tótem que emite el ticket, una pantalla de sala con la cola y anuncio por voz, y un panel del funcionario para llamar, re-llamar o cerrar atenciones. Diseñado para ser intuitivo para adultos mayores, el principal público de la farmacia.

Tecnologías utilizadas

React 19Frontend: las 3 vistas (tótem, sala y panel), con Vite y React Router
Express 5API REST del backend
PostgreSQLBase de datos: pacientes, casillas y tickets
SequelizeORM: modelos y creación automática de las tablas
Socket.IOCola y llamados en tiempo real, sin recargar
Web Speech APIAnuncio por voz del paciente llamado
